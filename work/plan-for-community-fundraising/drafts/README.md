## Produced in Draft Phase

### community-fundraising-strategy.md

A 6-month community fundraising strategy document for Food Bank Aid.

**Audience:** Trustees and staff (CEO, marcomms, fundraiser)

**Format:** Structured strategy document in markdown

**Contents:**
- Stated assumptions
- Strategic approach and core model
- Month-by-month execution plan (months 1–6)
- KPIs and leading indicators (monthly tracking table)
- Decision framework for trustees at 6 months
- Resource allocation guidance
- Risk register

**Why this format:** The brief called for a simple, structured strategy with clear KPIs. A single document with distinct sections lets trustees and staff read selectively — the fundraiser uses the execution plan, the CEO uses the decision framework, and the board uses the KPIs table.

**Status:** Ready for human review and light editing before use.
