# Issue #1: Design Agency Website

## Original Issue

I want to create a website for a design agency. It should use a novel, bold and simple colour scheme. It should use typography effectively with header and body fonts that are modern and clean. It should use minimal or no imagery but imaginative use of space on the page. I'm just looking for a demo so html with no backend is fine. The content should be synthetic, but should include the design ethos, perhaps with a list of values or an interesting way of scrolling or paging through them.
